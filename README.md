<h1>Тема "Классификация жанра фильма по описанию"</h1> 

***

<h2>Описание темы</h2>

Система классификации жанра фильма по текстовому описанию — прототип ML-сервиса, который определяет жанр фильма (drama, comedy, horror и др.) по короткому описанию на английском языке и предоставляет результат через веб-интерфейс.

<h2>Цель</h2>
Разработать, обучить и сравнить две модели классификации жанра фильма по тексту описания, выбрать из них лучшую и обернуть результат в работающий веб-интерфейс, который позволяет получать предсказание, переобучать модель и тестировать её на отложенных данных.

***

Источник данных: https://www.kaggle.com/datasets/abanoubyounanh/imdb-movies-genre-classification

Перед началом работы РАЗАРХИВИРУЙТЕ датасет.

Так же, создайте виртуальное окружение (в терминале введите python -m venv .venv)
Активируй его:
- Windows: `.venv\Scripts\activate`
- Mac/Linux: `source .venv/bin/activate`

В него установите пакеты (в терминале введите pip install -r requirements.txt)

П.С. В коде присутствует обученная модель, так что часть кода не активируется пока вы её не удалите (обучение очень долгое)
Это временная мера, пока мы не добавим нормальный интерфейс.
